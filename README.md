# Glimpsy

**Glimpsy** — бесплатная программа с открытым кодом. Весь день она работает в фоне
и сама сохраняет короткие фрагменты экрана в интересные моменты. Вечером собирает из них
динамичный ролик о вашей работе. Снимать процесс вручную не нужно.

Работает на Windows, macOS и Linux (X11 и Wayland). Все файлы остаются на вашем
компьютере, в интернет программа ничего не отправляет. Единственное, что она может
скачать, — модель распознавания речи для автосубтитров, и только когда вы сами нажмёте
«Субтитры».

> Раньше программа называлась **Worklapse**. При первом запуске Glimpsy сам переносит
> настройки, проекты, шрифты и модель субтитров; автозапуск тоже переключается.

> **Статус:** готовы рекордер с автосклейкой (этап 1), редактор с текстами и наложениями
> (этап 2), автозум к курсору, фоновая музыка, окошко с веб-камеры и автосубтитры (этап 3).
> (см. [Дорожную карту](#дорожная-карта)).

## Как это работает (простыми словами)

```
 ┌─────────────┐   видео кусочками по 1 с   ┌────────────────────┐
 │   FFmpeg    │ ─────────────────────────▶ │  Кольцевой буфер   │  хранятся последние 30 с,
 │ снимает     │                            │  (временная папка) │  старое удаляется
 │ монитор под │ ── миниатюры 64×36 ──┐     └─────────┬──────────┘
 │ курсором    │                      │               │ «сохрани последние N секунд»
 └─────────────┘                      ▼               ▼
 мышь, клики, клавиши ──▶  Оценка интересности ──▶ Умный рандом ──▶ Кандидаты (в 2–3 раза больше,
 (только количество)       каждой секунды                           чем нужно; слабые отсеиваются)
                                                                          │
                                         Ctrl+Alt+3 / «Собрать ролик»     ▼
                                                            Сборщик: лучшие фрагменты → MP4
```

1. **Запись идёт всё время, но «в кольцо».** FFmpeg пишет экран маленькими файлами
   по секунде и удаляет всё, что старше 30 секунд. На диске никогда не копятся часы видео.
2. **Снимается монитор под курсором.** Перешли на другой монитор — текущий фрагмент
   обрезается, начинается новый.
3. **Каждой секунде ставится оценка:** сколько двигалась мышь, сколько было кликов
   и нажатий клавиш, насколько изменилась картинка. Какие именно клавиши вы нажимали,
   программа **не запоминает**, только их количество.
4. **Умный рандом.** Раз в секунду программа «бросает кубик»: сохранить ли последние
   несколько секунд. Если на экране что-то происходит, шанс выше. Поэтому фрагменты
   идут не по расписанию, но чаще попадают на живые моменты.
5. **Кандидатов в 2–3 раза больше, чем нужно.** Когда их становится слишком много,
   программа убирает слабые или слишком похожие по времени. Так в запасе остаются
   интересные моменты со всего дня, а не только с утра.
6. **Сборка.** Все «важные моменты» попадают в ролик. Остальное время делится на равные
   части, и из каждой выбирается один фрагмент, причём активные выпадают чаще. Из каждого
   фрагмента берётся самый живой кусок. Всё приводится к 1920×1080, слегка ускоряется
   по выбранному темпу и склеивается.
7. **Автопауза.** Если вы ничего не делаете дольше минуты (например, ушли на обед),
   запись останавливается и сама продолжится, когда вы вернётесь.

## Установка готовой версии

Скачайте файл для своей системы на странице **Releases** этого репозитория.

**Обновления приходят сами.** Glimpsy время от времени проверяет, не вышла ли новая версия, и
предлагает «Обновить сейчас» — скачает её и перезапустится; проекты, настройки и модели остаются.
Проверить вручную — меню значка в трее → «Проверить обновления…», выключить — в «Настройках».
Самая свежая тестовая сборка — в релизе [dev](../../releases/tag/dev).

### Windows
1. Скачайте `Glimpsy-Windows-x64.zip`, распакуйте и запустите `Glimpsy.exe`.
   Есть и вариант одним файлом, `Glimpsy-Windows-x64-portable.exe`: его удобно
   переносить, но он дольше запускается.
2. Windows может предупредить, что программа «неизвестного издателя». Нажмите
   «Подробнее → Выполнить в любом случае»: у программы пока нет платной цифровой подписи.
3. **Установки нет** — программа сразу работает. При первом запуске появится окно
   с подсказкой. Дальше у Glimpsy нет большого окна — только **значок в трее** возле
   часов. Если его не видно, нажмите стрелку `^` рядом с часами и перетащите значок
   на панель задач, чтобы он был виден всегда.
4. Если запустить программу ещё раз, вторая копия не откроется, а первая покажет настройки.

### macOS
1. Скачайте `Glimpsy-macOS-arm64.zip` для Mac на M1–M4 или `Glimpsy-macOS-x86_64.zip`
   для Intel. Распакуйте и перенесите `Glimpsy.app` в «Программы».
2. **Первый запуск:** щёлкните по программе правой кнопкой и выберите «Открыть → Открыть»
   (программа без платной подписи Apple). Если macOS пишет, что файл «повреждён», выполните в Терминале:
   `xattr -cr /Applications/Glimpsy.app`
3. Выдайте разрешения в «Системных настройках → Конфиденциальность и безопасность»:
   - **Запись экрана**: без неё видео не пишется;
   - **Мониторинг ввода** и **Универсальный доступ**: для горячих клавиш и оценки активности.

   После этого перезапустите Glimpsy.
4. Иконка появится в строке меню, вверху справа. Значка в Dock у программы нет, так и задумано.

### Linux
1. Скачайте `Glimpsy-x86_64.AppImage` и разрешите запуск:
   `chmod +x Glimpsy-x86_64.AppImage && ./Glimpsy-x86_64.AppImage`
2. **Wayland** (Ubuntu 22.04+, Fedora и другие): понадобится GStreamer с поддержкой PipeWire.
   - Ubuntu/Debian: `sudo apt install gstreamer1.0-tools gstreamer1.0-pipewire`
   - Fedora: `sudo dnf install gstreamer1-plugins-base-tools pipewire-gstreamer`
   - Arch: `sudo pacman -S gstreamer gst-plugin-pipewire`
3. **GNOME:** иконка в трее появится только с расширением
   [AppIndicator](https://extensions.gnome.org/extension/615/appindicator-support/).
   Без него Glimpsy покажет маленькое окно-пульт.

## Как пользоваться

| Действие | Горячая клавиша | Или в меню трея |
|---|---|---|
| ⭐ Важный момент: сохранить 10 с до нажатия и 5 с после, фрагмент обязательно попадёт в ролик | **Ctrl+Alt+1** | «Отметить важный момент» |
| ⏸ Пауза / продолжить | **Ctrl+Alt+2** | «Пауза» |
| 🎬 Завершить сессию и собрать ролик | **Ctrl+Alt+3** | «Завершить и собрать ролик» |

Сочетания можно поменять в «Настройки → Горячие клавиши».

**Цвет иконки:** 🔴 идёт запись · 🟡 автопауза (нет активности) · ⚪ пауза ·
🟣 открыто приватное приложение · 🔵 собирается ролик.

Готовый ролик называется `Glimpsy_ГГГГ-ММ-ДД_ЧЧ-ММ.mp4` и попадает в папку из настроек
(по умолчанию «Видео/Glimpsy»). Если выбрать папку Google Drive, Яндекс Диска или Dropbox,
ролики будут сами уходить в облако. Черновики туда не попадают.

Если программа закрылась, не собрав ролик (выход, сбой, выключение), фрагменты не пропадут.
При следующем запуске Glimpsy предложит собрать ролик или продолжить запись.

### Настройки интенсивности

| Параметр | Что значит |
|---|---|
| Длина ролика | Сколько секунд должен длиться итоговый ролик (по умолчанию 60) |
| Длина фрагмента | От и до, сколько длится один кусочек в ролике (по умолчанию 2–5 с) |
| Темп | **Спокойный**: длинные фрагменты без ускорения. **Средний**: ×1.25. **Динамичный**: короткие фрагменты, ×1.6 |

Как часто сохранять моменты, программа считает сама: в начале дня чаще, потом реже.
Длину рабочего дня заранее знать не нужно.

### Приватность
- **Чёрный список** («Настройки → Приватность»). Пока в фокусе мессенджер, почта, банк
  или менеджер паролей, экран **вообще не пишется**, даже в буфер. Проверяются название
  программы и заголовок окна, поэтому слово `bank` сработает и для вкладки браузера с сайтом банка.
- Нажатые клавиши не записываются, только их количество в секунду.
- Пока идёт запись, уведомления самой программы не всплывают (иначе они попали бы в ролик):
  они покажутся, когда вы поставите паузу или соберёте ролик. «Важный момент отмечен» —
  это золотая звёздочка на значке в трее.
- Никаких серверов, аналитики и отправки данных.

### Только одно окно или несколько роликов сразу (потоки)
- По умолчанию пишется весь экран. Если нужно только одно окно (браузер, Figma, редактор) —
  трей → **Что записывать → Только одно окно…** → «Выбрать окно» и за 3 секунды щёлкните по нему.
  В ролик попадёт только это окно, без всего вокруг. Переключились на другое окно — запись
  ждёт (бирюзовая пауза на значке), вернулись — продолжается.
- Как узнавать окно: **только это окно**; **любое окно программы**; или **окна, в заголовке
  которых есть слово** — удобно для вкладки браузера или файла проекта.
- **Потоки:** можно выбрать до **3 окон** — например, проект А в одном, проект Б в другом. Они не
  смешиваются: при сборке каждое окно становится **отдельным роликом** и отдельным проектом
  в редакторе («Glimpsy_дата_Проект А.mp4»). Длина каждого — как в настройках.
- «Весь экран» в том же меню возвращает обычный режим. Выбор окон действует, пока программа
  запущена (номера окон после перезапуска меняются).
- На Wayland узнать активное окно нельзя, поэтому там режим недоступен.

### Звук и голосовой режим
- Glimpsy пишет **микрофон** и **звук компьютера** — то, что играет в колонках (на Mac — только
  микрофон: звук колонок без дополнительных программ записать нельзя). Настройки → **Звук**.
- **Голосовой режим:** пока вы говорите, фрагмент не режется и не ускоряется — речь попадает
  в ролик целиком и со звуком, сколько бы вы ни говорили (ролик от этого становится длиннее).
  Замолчали — дальше как обычно. Речь отличается от шума по громкости; порог сам подстраивается
  под тихую комнату или гудящий вентилятор, а «Чувствительность» — если голос тихий.
- У обычных фрагментов звук тоже сохраняется, но в ролике выключен: включить можно в
  редакторе у любого фрагмента. Раз в ролике есть речь — пригодятся и **автосубтитры**.
- На паузе и в приватных приложениях (звонок в мессенджере) микрофон не пишется.
  Звук хранится только в памяти (последние полминуты) и в фрагментах на этом компьютере.

### Веб-камера (по желанию)
- По умолчанию **выключена**. Включается в «Настройки → Камера»: редко (≈ раз в 10 минут),
  иногда (≈ раз в 5 минут) или часто (≈ раз в 2 минуты).
- Пока вы работаете, программа изредка снимает несколько секунд с камеры (в это время горит
  её лампочка) и сразу её выключает. В ролике эти кусочки появляются маленьким окошком
  в правом нижнем углу рядом с моментами, когда они сняты. В редакторе это обычные
  наложения: их можно подвинуть, увеличить или удалить.
- На паузе, в приватных приложениях и когда вас нет за компьютером камера не включается.
  Камеры нет или она занята — фрагменты просто пропускаются.
- macOS при первом включении спросит разрешение на доступ к камере.

## Редактор

Меню значка в трее → **«🎞 Редактор роликов…»**. Откроется список всех записанных сессий
(каждая — отдельный проект, новые сверху). Выберите сессию → **«Открыть в редакторе»**.

```
┌ Glimpsy · имя проекта ─────────────────────────── [Автомонтаж] [16:9 | 9:16]  [Экспорт ▾] ┐
│ Медиа   │                                         │ Свойства фрагмента,     │
│ Текст   │               просмотр                  │ текста, наложения       │
│ Субтитры│                                         │ или музыки              │
│ Наложение│  00:12.3 / 01:00.0      ▶        🔊──  │                         │
│ Музыка  ├─────────────────────────────────────────┴─────────────────────────┤
│ До/после│ ↶ ↷ │ ✂ 🗑                                      −  Вся лента  +  │
│Статистика│ лента: тексты · наложения · фрагменты · музыка                  │
│ Клавиши │                                                                  │
└─────────┴──────────────────────────────────────────────────────────────────┘
```

Внешний вид — тёмная тема в духе монтажных программ, шрифт **Inter** и иконки **Lucide**
(оба бесплатные, лежат в `assets/`). Все цвета собраны в одном файле `glimpsy/ui/theme.py`.

| Что сделать | Как |
|---|---|
| Выбрать фрагмент, перемотать | щелчок по фрагменту или по линейке времени |
| Переставить | перетащить фрагмент мышью |
| Обрезать | потянуть за левый или правый край фрагмента |
| Разрезать по курсору | **S** (или Ctrl+B) или «✂ Разрезать» |
| Удалить | **Delete** или **Backspace**, или «🗑 Удалить» |
| Автозум к курсору вкл/выкл | **Z** |
| Подсветка кликов вкл/выкл | **C** |
| Вписать / заполнить кадр | **F** / **G** |
| Добавить видео или фото | **M** |
| Экспорт | **Ctrl+E** (текущий формат) или кнопка «Экспорт» справа вверху: 16:9, 9:16 или **оба сразу** |
| Скорость, звук | панель свойств справа |
| Кадрирование (для Reels и не только) | в окне просмотра тащите кадр мышью; размер — уголки рамки или колёсико. Точные значения, «Вписать», «Заполнить», «Ко всем» — в панели справа. Кадр задаётся отдельно для 16:9 и 9:16 |
| Выбрать несколько фрагментов | **Shift+щелчок** (или Ctrl+щелчок) по ленте, **Ctrl+A** — все. Скорость, звук, кадр и удаление применяются ко всем выбранным |
| Вставить видео или фото | «＋ Добавить медиа», перетащить файлы на ленту или **Ctrl+V** (файлы, скопированные в Проводнике/Finder, или картинка из буфера обмена) |
| Отменить / повторить | **Ctrl+Z** / **Ctrl+Shift+Z** или **Ctrl+Y** |
| Пуск / пауза | **Пробел**; ← → — на кадр, Shift+← → — на секунду |
| Масштаб ленты | Ctrl+колёсико или кнопки «−», «+», «Вся лента» |

| Добавить текст | **T** (или Ctrl+T), «T Текст» — текст появится в месте курсора |
| Статистика сессии | «📊 Статистика»: сколько работали, сколько кликов и нажатий, в каких программах (только для вас, в ролик не попадает) |
| Наложить картинку или видео поверх ролика | «▣ Наложение» или перетащите файл на фиолетовую дорожку наложений |

Горячие клавиши работают **в любой раскладке**: Я — то же, что Z. Одиночные клавиши не
срабатывают, пока вы печатаете текст. Полный список — кнопка **⌨** слева от просмотра.

### Тексты
- Тексты лежат на отдельной дорожке над видео: их можно двигать по времени и тянуть за края.
- В окне просмотра текст перетаскивается мышью (у центра по горизонтали он «прилипает»).
- Справа настраиваются: шрифт (включая **свои** — кнопка «Добавить свой шрифт…», файлы .ttf/.otf
  сохраняются в программе и доступны во всех проектах), размер, цвет, жирный, курсив, тень,
  подложка (цвет, прозрачность, скругление), анимация (плавное появление, выезд снизу, всплытие)
  и положение (верх / центр / низ).
- **Стиль задаётся один раз** для всех текстов. Если нужно, у отдельного текста включите
  «Свой стиль для этого текста» — тогда он меняется независимо.
- Положение текста запоминается отдельно для 16:9 и 9:16.

### Автосубтитры
- Кнопка **«💬 Субтитры»**: программа распознаёт речь в ролике и расставляет фразы
  текстами на ленте. Язык определяется сам (или выберите: русский, английский, украинский…).
- Речь берётся из звука вставленных видео и наложений (например, ролик с телефона, где вы
  что-то рассказываете). Запись экрана идёт без звука, поэтому из неё субтитров не будет.
- При первом запуске программа предложит скачать модель распознавания: **«Быстрая»**
  (148 МБ) или **«Точная»** (488 МБ, лучше понимает русский). Модель скачивается один раз
  и хранится на компьютере. Сама речь распознаётся **прямо на компьютере**, звук никуда
  не отправляется.
- Строки: короткие (для Reels и Shorts) или обычные (для YouTube).
- Субтитры — обычные тексты с общим стилем: поменяйте шрифт, размер или подложку у любого,
  и изменятся все. Перетащите один — сдвинутся все субтитры. Ошибку в слове можно исправить
  прямо в тексте. «Удалить все автосубтитры» — на панели любого из них; повторное создание
  заменяет старые.
- Распознаёт [whisper.cpp](https://github.com/ggml-org/whisper.cpp) (открытая программа, MIT).

### Зум к кликам и подсветка кликов (как в Screen Studio)
Во время записи Glimpsy запоминает, где был курсор и где вы кликали. Поэтому ролик
получается живым, а не статичным кадром экрана:
- **Камера сама наезжает** туда, где вы кликаете (чуть заранее, плавно) и где работаете
  курсором в небольшой области, а когда курсор уходит далеко — плавно отдаляется.
- **Каждый клик отмечается** расходящимся жёлтым кругом с тёмной каймой — виден и на светлом,
  и на тёмном фоне.

Оба эффекта включены сразу в автоматически собранном ролике. Выключить или изменить силу
приближения — «Настройки → Ролик → Эффекты». В редакторе у каждого фрагмента в разделе
«Движение кадра» можно:
- **Камера** — кнопками:
  - **Автозум** — приближение к кликам и туда, где работает курсор;
  - **К стрелке** — кадр всё время приближен и плавно едет за курсором (сила — «Сила зума»);
  - **Наезд** — медленное приближение за время фрагмента;
  - **Зум на область** — обведите мышью в просмотре прямоугольник: камера плавно наедет на него,
    подержит и в конце отъедет («Выбрать область…» — обвести другую, Esc — отмена);
  - **Прокрутка ↓ ↑ ← →** — камера приближена и плавно проезжает по кадру: удобно для длинных
    страниц, макетов, таблиц.

  Зум на область, наезд и прокрутка работают и со своими вставленными видео.
- **«За курсором»** для 9:16
  (Reels/TikTok): из горизонтальной записи вырезается вертикальный кадр, который едет за курсором,
  чтобы важное не ушло за край. Три варианта:
  - **Жёстко** — курсор всегда в центре, кадр едет сразу за ним;
  - **Плавно** — кадр мягко догоняет курсор и стоит, пока курсор в середине;
  - **Зона + зум** — крупнее (×1.5), едет и вверх-вниз, двигается только при заметном смещении.

  Режим для 16:9 и для 9:16 запоминается отдельно: можно оставить автозум в горизонтальном
  ролике и «За курсором» в вертикальном.
- **Сила зума** — насколько приближать.
- **Подсвечивать клики** — включить или выключить круги.

Выберите все фрагменты (**Ctrl+A**), чтобы поменять сразу для всех. Работает для записей
экрана Glimpsy (для вставленных своих видео данных о курсоре нет). На Wayland, где положение
курсора программам недоступно, эффекты не работают.

### Плавный курсор (свой, как в Screen Studio)
- Экран записывается **без системного курсора**, а Glimpsy рисует свой — по точкам, где был
  курсор. Путь сглаживается, поэтому курсор **плывёт, а не дёргается**.
- Раз курсор рисуем мы, его можно поменять **после записи**: в редакторе у фрагмента — раздел
  **«Курсор (во всём ролике)»**: вид (стрелка, тёмная стрелка, точка, подсветка), **размер**
  (×0.5–×3) и «Показывать курсор».
- В автоматически собранном ролике — обычная белая стрелка.
- Выключить (снимать системный курсор как раньше) — «Настройки → Ролик → Плавный курсор».
  На Wayland положение курсора программам недоступно, поэтому там курсор всегда системный.

### Автомонтаж — одной кнопкой
Кнопка **«Автомонтаж»** сверху делает ролик динамичнее. В окне можно снять лишние пункты:
- **Автозум время от времени** — примерно каждый 2–3-й фрагмент, в первую очередь с кликами
  (если приближать везде, движение утомляет);
- **подсветка кликов**;
- **темп:** скучные фрагменты ускоряются, активные чуть замедляются (речь не трогается,
  важные моменты не ускоряются);
- **убрать пустые фрагменты**, где ничего не происходило (не больше трети ролика);
- **наезд камеры** — медленное приближение на важных моментах ⭐ (режим «Наезд» есть и в
  «Движении кадра» у любого фрагмента);
- **9:16 — кадр за курсором**: для вертикального формата отдельно ставится «За курсором»
  (на важных моментах — «Зона + зум»), а горизонтальный остаётся с автозумом;
- **разнообразие камеры** — на спокойных фрагментах между зумами иногда «к стрелке» или прокрутка;
- **склейки в долю музыки** — если добавлена музыка, Glimpsy находит её ритм и чуть подгоняет
  скорость фрагментов, чтобы склейки попадали в удары.

Всё это — обычные правки: любую можно поменять руками, а отменить сразу всё — **Ctrl+Z**.
Повторный запуск не ускоряет фрагменты ещё раз.

### Было → стало
Кнопка **«До/после»** слева делает короткую вставку, которая показывает результат работы.
Три варианта на выбор:
- **Шторка** — первый кадр работы, по нему проезжает шторка с ручкой и открывает последний;
- **Таймлапс** — вся работа, сжатая в несколько секунд, с полоской прогресса внизу
  (с потоками — таймлапс одного окна);
- **Стоп-кадр** — замерший первый кадр с плашкой «Было», резкая склейка — «Стало».

Можно выбрать длину и куда вставить (в конец, в начало или на место курсора). Вставка
появляется на ленте обычным фрагментом: её можно двигать, обрезать, ускорить или удалить.

### Наложения (картинка или видео поверх ролика)
- Логотип, макет, съёмка с телефона — всё, что должно быть **поверх** записи экрана.
- На фиолетовой дорожке наложение двигается по времени и тянется за края.
- В просмотре: перетащить — сдвинуть, уголки или колёсико — размер, кнопки «↖ ↑ ↗ …» — быстро
  поставить в угол, «На весь кадр» — закрыть весь экран.
- Настройки: прозрачность, скругление углов, тень; у видео — звук (подмешивается к ролику).

### Фоновая музыка
- Кнопка **«♪ Музыка»** сверху или просто перетащите mp3/wav/m4a/ogg/flac на ленту.
  Трек копируется в папку проекта и появляется зелёной дорожкой внизу ленты.
- Нажмите на зелёную дорожку — справа настройки: громкость, с какого места трека начать,
  плавное появление и затухание, повтор (если трек короче ролика).
- **«Тише, когда в ролике свой звук»** — музыка сама приглушается, пока звучит голос
  или звук вставленного видео.
- В просмотре слышна музыка с выбранной громкостью; появление, затухание и приглушение
  применяются в готовом ролике. Убрать — кнопка «Убрать музыку» или **Delete**.

### Улучшить: звук и картинка
Кнопка **«Улучшить»** слева в редакторе:
- **Чистый голос** — ползунок «сколько шума убирать» (вентилятор, гул, шипение). Убранное смешивается
  с исходным звуком, голос остаётся живым. Нейросеть RNNoise (0,3 МБ) скачивается один раз.
- **Одинаковая громкость** — уровень ролика (YouTube, подкаст, громко для Reels) и «подтягивать тихие места».
- **Как было / как будет** — послушать 8 секунд с места курсора.
- **Стабилизация** — сглаживает дрожание при съёмке с рук.
- **Яркость и цвет** — яркость, контраст, насыщенность, теплота и готовые стили; видно сразу в просмотре,
  «Сравнить» (держите) — как было снято.

### Фон за человеком на камере
Выберите окошко камеры → справа «Фон»: **убрать** (под человеком видно то, что ниже, например запись
экрана) или **размыть**. Нейросеть MODNet (≈25 МБ) скачивается один раз, видео камеры обрабатывается
один раз (примерно две минуты на минуту видео).

### Монтаж по тексту: дубли и поиск
- Режим **«Неудачные дубли»**: фразы, которые вы начали и сказали заново, подчёркнуты; отметьте и
  «Удалить все отмеченные» — останется последний вариант.
- В окне **«Мои сессии»** — поиск слова или фразы во всех проектах: где и когда это было сказано.

### Субтитры «караоке»
В стиле текста — **«Слова»**: подсветка цветом, слово на плашке, сказанное закрашивается или по одному
слову крупно. Время слов берётся из расшифровки речи.

### Сохранение: соцсети, главы, обложка
- В меню **«Экспорт»**: «Для YouTube», «Для Shorts, Reels, TikTok», «Для Telegram» (файл поменьше).
- **Быстрое сохранение** — если вы только вырезали куски, нетронутое видео не пересчитывается.
- **Главы для YouTube** — по тексту речи, правятся и копируются в описание; сохраняются рядом с роликом.
- **Обложка** — лучшие кадры на выбор (или своя картинка), крупный заголовок, сохранить JPEG/PNG.

## Автозапуск
При первом запуске в окне приветствия есть галочка «Запускать Glimpsy вместе с компьютером»
(включена по умолчанию). Потом её можно поменять в «Настройки → Запись».

- **Формат:** 16:9 для YouTube или 9:16 для Reels, TikTok и Shorts. Если кадр другой формы,
  фон заполняется его размытой копией, как в CapCut.
- **Правки сохраняются автоматически.** Исходный ролик не меняется, его можно открыть заново.
- **Экспорт** сохраняет новый файл рядом с исходным: `…_edit.mp4` (16:9) или `…_edit_9x16.mp4`.
  В меню кнопки есть **«Оба формата сразу»** — получатся два файла за один раз (у каждого
  формата своё кадрирование, положение текстов и движение кадра).
- Вставленные файлы копируются в папку проекта, поэтому проект не сломается, если удалить оригинал.
  Фото по умолчанию показывается 3 секунды.

## Особенности Linux: X11 и Wayland

Программа сама определяет, что у вас: X11 или Wayland.

| Возможность | X11 | Wayland |
|---|---|---|
| Запись экрана | ✅ x11grab | ✅ через системное окно «Поделиться экраном» (портал + PipeWire) |
| Монитор под курсором | ✅ | ⚠️ Нельзя: Wayland не сообщает программам, где курсор. Записывается монитор, выбранный в системном окне. Сменить: трей → «Монитор → Выбрать экран заново» |
| Горячие клавиши | ✅ | ⚠️ Через портал GlobalShortcuts (KDE Plasma 5.27+, GNOME 48+, Hyprland). Если окружение его не поддерживает, управляйте через трей |
| Чёрный список приложений | ✅ | ❌ Wayland не даёт узнать активное окно. Ставьте паузу вручную |
| Оценка активности | мышь, клавиатура, картинка | только изменение картинки |

Так устроена защита самого Wayland, и программа тут ничего не может изменить.
Когда что-то недоступно, Glimpsy не падает: при первом запуске он показывает сообщение,
что именно ограничено и почему. Эти же сведения есть в «Настройки → Система».

## Запуск из исходников

Нужен **Python 3.11 или новее** ([python.org](https://www.python.org/downloads/)).

```bash
git clone https://github.com/mrbobsterx-boop/Glimpsy.git
cd Glimpsy
python -m venv .venv
```

Активируйте окружение:
- Windows: `.venv\Scripts\activate`
- macOS / Linux: `source .venv/bin/activate`

Дальше команды одинаковые для всех систем:

```bash
pip install -r requirements-dev.txt
python scripts/fetch_ffmpeg.py     # скачает FFmpeg в vendor/ffmpeg (один раз)
python scripts/build_whisper.py    # соберёт whisper.cpp для автосубтитров (один раз, нужны CMake и C++)
python -m glimpsy                # запуск
```

На Linux для PySide6 могут понадобиться системные библиотеки (Ubuntu/Debian):
```bash
sudo apt install libegl1 libxkbcommon-x11-0 libxcb-cursor0 libxcb-icccm4 libxcb-keysyms1 \
  libxcb-shape0 libxcb-xinerama0 libxcb-randr0 libxcb-render-util0 libxcb-image0
```

Тесты:
```bash
python -m pytest
# Linux: полная проверка записи на виртуальном экране
xvfb-run -a -s "-screen 0 1280x720x24" python -m pytest
```

Журнал работы (пригодится, если что-то пошло не так):
- Windows: `%LOCALAPPDATA%\Glimpsy\Logs\glimpsy.log`
- macOS: `~/Library/Logs/Glimpsy/glimpsy.log`
- Linux: `~/.local/state/Glimpsy/log/glimpsy.log`

## Сборка своими руками

```bash
pip install -r requirements-dev.txt
python scripts/fetch_ffmpeg.py
python scripts/build_whisper.py    # можно пропустить — тогда в сборке не будет автосубтитров
pyinstaller glimpsy.spec --noconfirm
```

| Система | Результат |
|---|---|
| Windows | `dist/Glimpsy/Glimpsy.exe` (папка целиком). Одним файлом: `set GLIMPSY_ONEFILE=1` перед сборкой |
| macOS | `dist/Glimpsy.app` |
| Linux | `dist/Glimpsy/`, затем `bash packaging/linux/build_appimage.sh` → `dist/Glimpsy-x86_64.AppImage` |

Собирать нужно на той системе, для которой нужна сборка: PyInstaller не умеет собирать
программу для Windows на Mac и наоборот. Поэтому все три сборки делает GitHub Actions.

## Автосборка на GitHub

Файл `.github/workflows/build.yml` на серверах GitHub запускает тесты и собирает программу
для Windows, macOS (Apple Silicon и Intel) и Linux.

- **При каждом push:** готовые файлы лежат во вкладке **Actions → нужный запуск → Artifacts**.
- **Выпуск версии:** поменяйте номер в `glimpsy/__init__.py` (например, на `0.2.0`) и влейте
  изменения в ветку `main`. Через 5–10 минут на странице **Releases** появится релиз
  `v0.2.0` со всеми файлами. Каждое следующее обновление `main` с тем же номером просто
  обновляет файлы в этом релизе.

## Ключевые решения

- **Экран снимает FFmpeg, а не Python.** Python только говорит, какой монитор снимать.
  Кадры не проходят через Python, поэтому процессор почти не нагружается.
- **Буфер — это файлы по одной секунде (MPEG-TS).** Такие файлы можно склеивать простым
  копированием, без перекодирования. Поэтому сохранение момента мгновенное и ничего не нагружает.
- **Аппаратное кодирование** (NVENC, Quick Sync, AMF, VideoToolbox, VAAPI). При запуске
  программа пробует каждый кодек на тестовом видео и берёт первый рабочий. Если ни один
  не подошёл, включается программный libx264: запись работает, но процессор нагружен сильнее.
- **Быстрый захват на Windows** (ddagrab) берёт картинку прямо из видеокарты. Если он
  не работает (старая Windows или удалённый рабочий стол), программа сама переходит на gdigrab.
- **Миниатюры для сравнения кадров** FFmpeg делает попутно, почти бесплатно.
- **Платформенный код изолирован** в `glimpsy/platform/`. Остальная программа не знает,
  на какой она ОС, и работает с общим интерфейсом из `base.py`.
- **Запасные режимы вместо падений:** нет трея — окно-пульт; нет горячих клавиш — меню
  трея; не удалось определить курсор — выбор монитора вручную.
- **OpenCV** не понадобился: для сравнения миниатюр хватает numpy, камеру снимает сам FFmpeg,
  автозум считается по координатам курсора. Так сборка меньше.

## Где хранятся файлы

| Что | Где | Когда удаляется |
|---|---|---|
| Буфер, черновые фрагменты и кусочки с камеры | системная временная папка → `Glimpsy/session_…` | сразу после сборки ролика |
| Готовые ролики | папка из настроек | никогда (это ваши файлы) |
| Модели распознавания речи | папка данных программы → `models/` | остаются для следующих роликов; удалить можно вручную |
| Проекты редактора (фрагменты, правки, вставленные файлы) | папка данных программы → `projects/` | остаются, чтобы ролик можно было переделать. Удалить: трей → **«🧹 Очистить кэш…»** (все сразу) или «Удалить…» у отдельной сессии в списке |
| Миниатюры и временные файлы экспорта | системная временная папка → `Glimpsy/` | трей → «🧹 Очистить кэш…» |
| Настройки | Windows: `%LOCALAPPDATA%\Glimpsy`, macOS: `~/Library/Application Support/Glimpsy`, Linux: `~/.config/Glimpsy` | — |

## Если что-то не работает

- **Чёрное видео на macOS** — нет разрешения «Запись экрана». Выдайте его и перезапустите программу.
- **Горячие клавиши не срабатывают на macOS** — нужны разрешения «Мониторинг ввода» и «Универсальный доступ».
- **Высокая нагрузка на процессор** — в «Настройки → Система» видно, какой кодек выбран.
  Если там «Программный», обновите драйвер видеокарты. Можно также уменьшить
  «Макс. высоту записи» и частоту кадров.
- **Записывается не тот монитор на Windows** — в `settings.json` укажите `"capture_backend": "gdigrab"`.
- **Любая другая проблема** — откройте issue на GitHub и приложите журнал `glimpsy.log`.
